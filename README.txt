WEB CLIENT OS icon replacement

This package mirrors the repository paths needed for the new icon.
Copy these files over the same paths in the WEB CLIENT OS repository, then commit and deploy:

assets/brand-icon.svg
client/public/brand-icon.svg
client/public/brand-mark.svg
favicon.ico
client/public/favicon.ico

The SVG mark combines a browser frame, rising signal, cursor, and violet highlight. The ICO is exported at several browser friendly sizes.
